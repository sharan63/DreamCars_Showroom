Project structure

This website follows the uploaded exam brief: index.html is the home page; the home page uses a three-column layout; content pages use two-column layouts; HTML files are in the root folder; stylesheets are in styles/; images/ is provided for image assets.

It includes main.css for the home page, content.css for other pages and normalize.css on every page. The contact page includes a Bootstrap carousel, an audio file link and a PDF catalogue link as required on page 7 of the instructions.

DreamCars is a fictional educational project, not an authorized dealership.
